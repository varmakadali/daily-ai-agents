# Daily AI Agents 🤖

A learning-by-building repository for experimenting with AI agents, automation, and AI-powered workflows.

## 🎯 Goal

Build small, practical AI systems while learning the ideas behind modern agentic applications.

## 🧠 Topics

- LLM applications
- AI agents
- Prompt design
- Tool use
- Automation
- APIs and integrations
- Evaluation and reliability

## 📌 Direction

Each experiment asks one question:

**Can I turn this AI concept into working software?**

## 🚧 Status

Actively evolving as I learn and build.
